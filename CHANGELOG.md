# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-06-02

### Added
- Added `CHEATSHEET.md` mapping the custom Spec Kit workflow with the `gemini` integration.
- Added comprehensive repository compliance files (`pyproject.toml`, `cliff.toml`, `.editorconfig`, `.gitleaks.toml`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `LICENSE`, `USER_MANUAL.md`, `Dockerfile`, `.dockerignore`).
- Configured Ruff and Mypy settings for backend formatting and robust type checking.

### Changed
- Re-styled login card component back to light theme as requested by the user.
- Updated header banner cards and navigation style.

---

## [1.0.0] - 2026-06-01

### Added
- Initial Proof of Concept release for DigAlert.
- Centralized permit registration database schemas and migrations.
- 4D Clash Detection Engine using spatial, temporal, and depth overlaps.
- Co-Dig Recommendation Engine with dynamic savings calculation.
- Interactive map powered by Leaflet.
- Citizen complaint form with live tracking.
- Interactive Admin dashboard with Recharts visualizations.
